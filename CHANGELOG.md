# Changelog

All notable changes to **The Nile** will be documented in this file.

## [v1.0] - Initial Release

- 🔒 **Multi-state vault**: Support for Locked, Unlocked, and Decoy states.
- 📱 **Dial code activation**: Access hidden vault interface via phone dialer codes (`*#*#CODE#*#*`).
- 🎭 **Calculator decoy app**: Disguise app interface as a functional calculator.
- 💥 **Fake crash screen**: Present fake force-close crash screen with hidden long-press bypass.
- 👤 **Multi-profile support**: Multiple profiles with per-profile decoy PINs.
- 🔐 **AES-256-GCM encrypted backups**: Fast, secure backups powered by Rust native crypto.
- 📦 **App hiding**: Deep app cloaking via LSPosed/Xposed.
- 📁 **Directory hiding**: Filesystem directory hiding using LUKS containers.
- 🧹 **Trace cleaning**: Automated scrubbing of logs, recent tasks, and system cache.
- 🎨 **Material You / Dynamic theming**: Modern UI with full dynamic theming support.
- ⌨️ **Convenience shortcuts**: Quick Settings tile, deep links, and volume key shortcuts.
- 🙈 **Launcher icon hiding**: Hide app launcher icon for maximum stealth.
